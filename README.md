# python-sqlite-sales-project

📊 Simple Sales Data Analysis with Python & SQLite
[Python 3.8+ Badge] [MIT License Badge] [Completed Status Badge] [Made with ❤️ in India Badge]

✨ Overview
A beginner-friendly project that teaches you how to:
🛒 Build a sales database using SQLite.
🐍 Query sales reports inside Python.
📈 Display results with tables and bar charts.
🎯 Analyze total quantity sold and revenue.

🚀 Perfect for learning SQL, pandas, matplotlib, and basic data analysis!

🛠️ Tech Stack
- Python 3: Programming language
- SQLite3: Local database
- Pandas: Data analysis
- Matplotlib: Data visualization

📥 Installation
1. Clone the repository:
   git clone https://github.com/your-username/sales-data-analysis.git
   cd sales-data-analysis

2. Install the required libraries:
   pip install pandas matplotlib

🚀 How to Use
1. Create Database:
   Run the script that creates sales_data.db with Indian product sales.

2. Analyze Data:
   Execute the analysis script to:
   - Print Total Quantity Sold and Total Revenue.
   - Plot a bar chart showing revenue per product.

3. Bonus:
   Expand the database by adding cities, dates, or categories!
